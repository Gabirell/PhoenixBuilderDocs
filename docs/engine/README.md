# Phoenix Engine Documentation

Phoenix Engine is a custom Swift game engine that runs game levels built using the Phoenix Ecosystem.

## Role in the Ecosystem
* **Runtime rendering**: Consume and render compiled primitives and building assets.
* **Semantic execution**: Interact with the architectural semantic metadata in-game.
* **Validation**: Run production scenarios (e.g., in the validation game HowNotToDie) to test and validate builder mechanics.
