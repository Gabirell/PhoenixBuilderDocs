# Phoenix Forge Documentation

Phoenix Forge is the Blender Add-on for the Phoenix Ecosystem. It is responsible for semantic asset creation and metadata authoring.

## Role in the Ecosystem
* **Authoring**: Define sockets, material interfaces, bounding boxes, and LOD parameters inside Blender.
* **Validation**: Run validation checks to ensure assets comply with the Phoenix SDK.
* **Exporting**: Compile assets into `.pba` (Phoenix Building Asset) packages.
