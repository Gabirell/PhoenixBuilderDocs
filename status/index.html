Como o painel se atualiza

Cada card possui uma etapa manual, editável no próprio HTML, e uma camada live. A camada live consulta o último commit do repositório correspondente diretamente na API pública do GitHub.
Não há banco de dados nem processo de build para o estado. Um novo commit aparece no painel na próxima atualização automática ou ao clicar em Atualizar agora.
Intervalo atual: 5 minutos. Isso evita consumir desnecessariamente o limite da API pública do GitHub.
